# TaskFlow Manager

![Deploy](https://github.com/Salama-Malek/taskflow-manager/actions/workflows/deploy.yml/badge.svg)

Live demo: https://salama-malek.github.io/taskflow-manager/

A drag-and-drop Kanban task board built with React, TypeScript, and Tailwind CSS.

## Overview

TaskFlow Manager is a client-side productivity app for organizing work across three columns
(To Do, In Progress, Done). Tasks carry a title, description, priority, and due date, can be
reordered or moved between columns via drag and drop, and persist locally in the browser. The
app ships with light/dark themes and full English, Arabic, and Russian localization (including
RTL support for Arabic), plus a statistics view that summarizes throughput and upcoming
deadlines.

## Features

- Kanban board with three status columns and drag-and-drop reordering/movement (`@dnd-kit`)
- Create, edit, and delete tasks through a modal form with validation (`react-hook-form`)
- Priority levels (low/medium/high) and due dates, with search and priority filtering
- Statistics page with completion, due-soon, and overdue counts and weekly throughput
- Light/dark theme toggle
- Multi-language UI (English, Arabic, Russian) via `i18next`, with automatic language detection
- Toast notifications for task actions (added/updated/deleted)
- Data persisted to `localStorage`, no backend required
- Responsive layout with a collapsible sidebar and mobile navigation drawer

## Tech stack

- React 18 + TypeScript
- Vite (build tool and dev server)
- Tailwind CSS (with `@tailwindcss/forms`)
- React Router
- Framer Motion (animations/transitions)
- Headless UI, Heroicons, Radix Toast primitives
- `@dnd-kit` (drag and drop)
- `i18next` / `react-i18next` (internationalization)
- `date-fns`, `uuid`
- GitHub Actions + GitHub Pages for deployment

## Getting started

### Prerequisites

- Node.js 18+
- npm

### Install

```bash
npm install
```

### Run in development

```bash
npm run dev
```

Starts the Vite dev server on `http://localhost:5173` and opens it automatically.

### Build for production

```bash
npm run build
```

Type-checks the project (`tsc`) and builds the production bundle into `dist/`.

### Preview the production build

```bash
npm run preview
```

### Lint

```bash
npm run lint
```

### Deploy

```bash
npm run deploy
```

Publishes `dist/` to the `gh-pages` branch. The repository also includes a GitHub Actions
workflow (`.github/workflows/deploy.yml`) that builds and deploys to GitHub Pages automatically
on every push to `main`.

### Environment variables

None required. All state is stored in the browser's `localStorage`.

## Project structure

```
src/
  components/     Reusable UI: board, columns, cards, modal, header, sidebar, toasts, theme toggle
  context/         React contexts for tasks, theme, and language state
  hooks/           Task logic, localStorage persistence, theme, and language hooks
  i18n/            Translation files (en, ar, ru) and i18next setup
  pages/           Route-level views: Home, Statistics, Settings, About
  styles/          Global Tailwind/CSS entry point
  App.tsx          App shell, routing, and layout
  main.tsx         React entry point
public/            Static assets (favicon, logo)
.github/workflows/ CI workflow for building and deploying to GitHub Pages
```

## Notes

- Vite's `base` is configured for GitHub Pages under `/taskflow-manager/`; adjust
  `vite.config.ts` if deploying elsewhere.
- The `dist/` directory in this repository is a built output checked in alongside source;
  it is regenerated by `npm run build`.
